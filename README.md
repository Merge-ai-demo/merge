# Merge

Réviser ses cours avec une IA qui tourne sur ton Mac : fiches, cartes, QCM, écrits à partir de tes cours. Gratuit. Rien n'est envoyé sur Internet.

**Télécharger :** https://github.com/Merge-ai-demo/merge/releases/latest

L'IA (Gemma 4, licence Apache 2.0) est hébergée sur https://huggingface.co/Merge-ai-demo/merge-ia et s'installe depuis l'app.
